# ESP32 蓝牙热敏打印机 (ESP32_BT_printer)

基于 ESP32-WROOM-32E + JX-2R-01 打印头（384 点 / 48mm 可打印宽）的便携热敏打印机，
VS Code + PlatformIO + Arduino 框架。

## 现在能做什么

- [x] 按键手动送纸 10mm（缺纸时只走纸、不打印）
- [x] 打印头驱动：SPI 送数、LAY 锁存、6 段 STB 分段加热、VH 升压使能
- [x] 步进电机走纸（八拍，32 步/mm）
- [x] 缺纸检测（GPIO35，2 秒一次非阻塞告警）
- [x] 电池电压 / 电量查表 + **低电分级保护**（<3.55V 拒绝开始，打印中 <3.40V 中止）
- [x] 打印头 NTC 测温 + **温度补偿**（≥50℃ 起缩短加热时间，≥80℃ 中止）
- [x] 状态灯：打印中常亮 / 缺纸过温快闪 / 低电慢闪
- [x] 空闲自动待机（关蓝牙、关打印头电源，按键唤醒）
- [x] 经典蓝牙 SPP，设备名 `MaoPaperang_Q`
- [x] 喵喵机 App 协议：帧解析、CRC32 双规则、ACK、**握手 10 连**、**打印数据通路**
- [x] 内置自检图案（程序生成，不占 Flash）、链路排空防串帧

## 上位机

一台打印机，手机和电脑都能当上位机，**同一时刻只能连一个**：

| 上位机 | 连接方式 | 说明 |
|---|---|---|
| 安卓手机 | 经典蓝牙 SPP | 系统蓝牙里配对 `MaoPaperang_Q`，再装喵喵机 App 或自制 App |
| Windows 电脑 | 经典蓝牙 SPP → COM 口 | 配对后在"设备和打印机 → 属性 → 服务"里勾选串行端口，用"传出"COM |
| iPhone | ❌ 用不了 | iOS 第三方 App 只开放 BLE，需改固件 |

调试最快的方式：串口蓝牙助手发 HEX。发 `02 04 00 00 00 21 95 76 35 03`（GET_VERSION），
应收到 `02 04 00 01 00 00 46 89 5E 9E 03`。

## 通信协议

```
0x02 | type | idx | len(2,LE) | payload | CRC32(4,LE) | 0x03
```

- CRC32 **用 crcKey `0x35769521` 作初值**（不是标准 zlib 的 0xFFFFFFFF），且**只覆盖 payload**；
  空载荷帧的 CRC 因此恒等于 `0x35769521`（真机实测，见 `src/frame.cpp` 顶部）；
- 校验时对"标准 zlib / 覆盖帧头"等旧写法也放行，命中非主规则会在串口打出规则编号；
- 查询类指令回 `SENT_*` 数据帧，其余回 11 字节 ACK；
- 握手顺序、打印流程、指令表见 [`文档/项目总结.md`](文档/项目总结.md) 与
  [`文档/项目总结文档.docx`](文档/项目总结文档.docx)。

## 保护阈值

| 项目 | 阈值 | 动作 |
|---|---|---|
| 缺纸 | PHINT 高电平 | 绝不加热，打印前/每行检查 |
| 低电（开始） | < 3.55 V | 拒绝开始打印 |
| 低电（打印中） | < 3.40 V | 立即中止，防止掉压复位 |
| 打印头温度 | ≥ 50 ℃ | 线性缩短加热时间（80℃ 时 70%） |
| 打印头温度 | ≥ 80 ℃ | 立即中止 |
| 空闲 | 默认 60 分钟（App 可设） | 进入待机，关闭蓝牙 |

## 编译与烧录

```bash
pip install platformio          # 或直接用 VS Code PlatformIO 插件
python 工具/patch_bt_rx_queue.py # 必须：把蓝牙接收队列 512 改成 20480，否则大图丢包
pio run                         # 编译
pio run -t upload               # 烧录（默认 COM 口，可按需改 platformio.ini）
pio device monitor              # 串口日志 115200
```

> 框架升级后 `工具/patch_bt_rx_queue.py` 需要重新执行（它改的是 PlatformIO 包里的文件）。

## 注意

- **速度**：单段加热 3.5ms × 6 段串行，一行约 34ms ≈ 3.7mm/s，A4 就别想了，
  30mm 以内的小票/便签才舒服。发热、升压回充、电池掉压是三条硬约束。
- **分区**：当前 `default.csv`，Flash 已用 82.2%，加中文字库（GB2312 约 211KB）需换 `huge_app.csv`。
- **保护**：缺纸绝不加热；过温中止并补偿；低电拒绝新任务。铁律见 [`文档/笔记.md`](文档/笔记.md)。
- **串帧防护**：打印结束/中止后会排空蓝牙链路并复位解析器，避免上一单残留被当成新指令。
