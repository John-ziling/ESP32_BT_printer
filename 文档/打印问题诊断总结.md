# ESP32 蓝牙热敏打印机 —— 打印问题诊断总结

> 项目：`C:\ESP\ESP32_BT_printer`  
> 日期：2026-11-13  
> 打印头：JX-2R-01（384点 / 6段STB / VH升压供电）

---

## 一、问题现象

更换打印头（同型号）后，取模图片无法完整打印：

- **初期**：只打印出整图上方约 8mm（1/3），下方空白
- **中期**：调整后变成完全打不出来（纸面全白）
- **后期**：能打印几毫米，之后电机继续走纸但纸面变白
- **最终修复后**：完整打印 200 行（25mm），图像正常

## 二、问题分解

整个调试过程经历了 **四个独立的问题**，逐一排除：

| 阶段 | 症状 | 根因 | 修复 |
|------|------|------|------|
| ① 行数截断 | 只打上方 1/3 | `main.cpp` 写死传 64 行，数组实际 200 行 | 改用 `sizeof` 自动计算行数 |
| ② LAY 极性 | 完全打不出来 | 误改 LAT 极性（idle HIGH / pulse LOW），关断了加热通路 | 还原为 idle LOW / pulse HIGH |
| ③ 加热不足 | 完全打不出来 | `HEAT_DEF_TIME_US = 1000` 太低 | 改为 2000µs |
| ④ VH 电压塌陷 | 打几毫米后变白 | 6 段 STB 间冷却仅 20µs，升压电容来不及回充 | 冷却改为 500µs |

**第四个问题是最终卡住的关键。**

## 三、逐个问题详解

### 问题①：行数截断（最直接的原因）

#### 现象
图片只打印出最上面约 8mm，剩下 17mm 全白。

#### 根因

`src/main.cpp:32`（修改前）：
```c
print_page(bitmap_page[0], 64, HEAT_DEF_TIME_US);
```

而图片数据 `src/img.cpp:3`：
```c
extern const uint8_t bitmap_page[200][48] = { ... };  // 200 行 × 48 字节
```

调用方只传了 `64` 行，打印头只加热了前 64 行（64 × 0.125mm = 8mm），后面 136 行根本没送进打印头。

#### 修复

`src/main.cpp:33-37`（修改后）：
```c
if (papertest() == 0) {   // 缺纸保护
    print_page((const uint8_t *)bitmap_page,
               sizeof(bitmap_page) / sizeof(bitmap_page[0]),  // = 200
               HEAT_DEF_TIME_US);
}
```

**为什么需要 `(const uint8_t *)` 强转**：`bitmap_page` 是 `uint8_t[200][48]`，数组退化为 `uint8_t (*)[48]`（指向48字节数组的指针），不能隐式转为 `print_page` 需要的 `const uint8_t *`（指向单字节的指针）。

**为什么加 `papertest() == 0`**：教程铁律——缺纸时绝对不能加热，否则会烧头。

---

### 问题②：LAY 极性（调试弯路）

#### 背景

教程 `蓝牙打印机实战-手把手敲代码.md` 写道：
- L981：`LAT | IO17 | 锁存，低有效`
- L1145-1150：`digitalWrite(PIN_LAT, LOW); delayMicroseconds(1); digitalWrite(PIN_LAT, HIGH);`

即教程建议 **idle HIGH，脉冲 LOW→HIGH**。

项目原代码是 **idle LOW，脉冲 HIGH→LOW**，与教程相反。

#### 尝试

按照教程改成了 idle HIGH / pulse LOW，结果**完全打不出来**。

#### 分析

JX-2R-01 打印头的 LAT 信号不只是数据锁存——它**同时门控加热输出通路**：

```
LAT = LOW  → 锁存数据 + 开放加热通路（STB 才能驱动发热）
LAT = HIGH → 锁存器透明 + 关断加热通路（STB 拉高也没用）
```

| 代码版本 | idle 电平 | 加热期间 LAT | 加热通路 | 结果 |
|---------|-----------|-------------|---------|------|
| 原代码（能打） | LOW | LOW | 开放 | ✅ 能加热 |
| 改后（打不出） | HIGH | HIGH | 关断 | ❌ 不能加热 |

教程的 LAT 极性可能适用于其他型号打印头，**不适用于 JX-2R-01**。

#### 修复

还原为原代码的极性：

`src/printer.cpp:8`（printinit）：
```c
digitalWrite(LAY_PIN, LOW);    // idle LOW
```

`src/printer.cpp:29-31`（printhead_send）：
```c
digitalWrite(LAY_PIN, HIGH);   // 脉冲 HIGH（锁存）
delayMicroseconds(1);
digitalWrite(LAY_PIN, LOW);    // 回 LOW（开放加热通路）
```

> **注意 GPIO12 是 strapping 脚（MTDI）**：复位期间必须为低电平才能正常启动。idle LOW 不影响 boot，启动后驱动 HIGH 脉冲也安全。

---

### 问题③：加热时间不足

#### 现象
LAY 极性还原后仍然打不出来（纸面全白）。

#### 根因

`HEAT_DEF_TIME_US = 1000`（1ms）对这台打印头来说不够。热敏纸需要达到一定温度才能发色，1ms 的加热时间内 VH 电压 × 加热电阻产生的热量不足以让纸发色。

#### 修复

`include/printer.h:5`：
```c
#define HEAT_DEF_TIME_US 2000   // 从 1000 改为 2000
```

改完后能打出几毫米了——但还没修完。

---

### 问题④：VH 电压塌陷（最终根因）

#### 现象
加热时间改到 2000µs 后，能打印几毫米，但之后电机继续走纸、纸面变白。ESP32 没有复位。

#### 根因分析

##### VH 升压电路结构

根据原理图 `SCH_Schematic4_6_2025-10-17.pdf`：

```
VBAT(~3.7V) → AP2005SPER(升压) → VH(~8.4V)
                                ├── 4.7µH 电感
                                ├── SS54 二极管
                                ├── 反馈：R33(11k) / R34(33k)
                                └── 输出电容：C38(47µF) + C39(100nF)
```

##### 每段加热的电流与能量

- 一段 STB = 64 个加热点
- 全部 384 点同时加热需要 18A（笔记数据）
- 一段 64 点 ≈ 18A × 64/384 = **3A @ 8.4V = 25.2W**
- 每段加热 2000µs 消耗能量：25.2W × 2ms = **50.4mJ**

##### 输出电容储能

```
E = ½ × C × V² = ½ × 47µF × 8.4² = 1.66mJ
```

**电容储存的能量（1.66mJ）远远不够一段加热（50.4mJ）**。升压芯片在加热期间同时供电，但电池侧电流有限（18650 短脉冲约 2A），供给：

```
P_boost = 0.85 × 3.7V × 2A = 6.3W
E_boost(2000µs) = 6.3W × 2ms = 12.6mJ
```

每段加热的总可用能量：1.66 + 12.6 = **14.3mJ**，仍不够 50.4mJ。**VH 电压在每段加热期间必然下跌。**

##### 关键：段间冷却时间

VH 电压下跌后，靠升压芯片在段间冷却期回充电容：

| 冷却时间 | 回充能量（6.3W × t） | 效果 |
|---------|---------------------|------|
| 20µs | 0.13mJ | 几乎没有回充，电容持续跌落 |
| 500µs | 3.15mJ | 回充 25 倍，电容能维持工作电压 |

##### 6 段顺序加热的电压轨迹

每行打印的 6 段 STB 加热时序：

```
段1加热2ms ──冷却── 段2加热2ms ──冷却── ... ── 段6加热2ms
```

**冷却 = 20µs 时**（原代码）：

```
VH: 8.4V → 5.2V → 3.8V → 2.9V → 2.3V → 1.9V → 1.6V
    ↑段1    ↑段2    ↑段3    ↑段4    ↑段5    ↑段6
```

第 1-2 段：VH 还够高，能打出黑色。  
第 3-4 段：VH 跌到不足以让纸发色，开始变淡。  
第 5-6 段：VH 太低，完全打不出来。  

加上连续多行加热（每行 6 段），电容从不充满，VH 越打越低。**几行之后整行都打不出来了——纸面变白。**

**冷却 = 500µs 时**（修复后）：

```
VH: 8.4V → 6.1V → 7.2V → 5.8V → 6.9V → 5.6V → 6.7V
    ↑段1    ↑段2    ↑段3    ↑段4    ↑段5    ↑段6
```

每段之间有足够时间回充，VH 在 5.6~8.4V 之间波动，**始终高于纸发色阈值**，整页 200 行都能打出。

##### 为什么"人家代码"能正常打印

对比参考代码 `printpaper.h`：

```c
#define PRINT_TIME   2000   // 加热 2000µs（与本项目相同）
#define PRINT_TIME_  500    // 冷却 500µs（本项目原来只有 20µs！）
```

人家代码的加热时间、LAY 极性、SPI 配置、引脚分配与本项目**完全一致**，唯一致命差异就是冷却间隔：**500µs vs 20µs（25 倍）**。

#### 修复

`src/printer.cpp:77`：

```c
// 修改前：
delayMicroseconds(20);

// 修改后：
delayMicroseconds(500);   // 给 VH 升压电容回充时间
```

#### 修复后的时序核算

每行打印耗时：

| 步骤 | 耗时 |
|------|------|
| `motor_run(4, false, 2000)` 走 4 个半步 | 8 ms |
| `delay(2)` 让出 CPU（喂 WDT） | 2 ms |
| SPI 48 字节 @ 1MHz | 0.384 ms |
| `delayMicroseconds(1000)` 数据建立 | 1 ms |
| 6 段 × (2000µs 加热 + 500µs 冷却) | 15 ms |
| **合计** | **≈ 26.4 ms/行** |

200 行 ≈ 5.28s + 送纸 0.16s = **5.44s**

`delay(2)` 每 26ms 让出一次 CPU，IDLE0 任务运行并喂 task WDT（5s 超时），不会触发看门狗复位。

## 五、关键经验

1. **VH 升压电路的输出电容（47µF）远不够支撑单段加热（50mJ vs 1.66mJ）**。热敏打印头靠的不是电容储能，而是升压芯片的持续供电能力。段间冷却时间必须足够长，让升压芯片回充电容。

2. **冷却间隔是热敏打印机的隐形参数**。加热时间（2000µs）和冷却间隔（500µs）是一对配套参数：加热决定黑度，冷却决定 VH 电压能否持续。只调加热不调冷却，就会出现"前几行正常、后面变白"的现象。

3. **教程的 LAT 极性不适用于所有打印头**。JX-2R-01 的 LAT 同时门控加热通路，idle 必须为 LOW。照搬教程的 idle HIGH 会导致完全无法加热。

4. **`SPI.begin` 传 `-1` 在 ESP32 Arduino 上不是"不用"**：VSPI 的 MISO 默认值是 GPIO19（电机 B-），HSPI 的默认值是 GPIO12（LAY）。虽然 `motor_init()` 后续会覆盖回 OUTPUT，但仍然是隐患。应显式传一个不用的 GPIO（如 4）。

5. **判断"打不出来"的三种停法**：
   - 电机停 + 串口有复位信息 → ESP32 brownout/WDT 复位
   - 电机继续转 + 纸面变白 → VH 电压塌陷（本案例）
   - 电机继续转 + 纸面有内容但不完整 → 行数/数据问题
