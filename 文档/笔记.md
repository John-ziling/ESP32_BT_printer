## 蓝牙打印头与SPI：

SPI的使用：

```c
SPI.beginTransaction(HEAD_SPI); 

// 发送数据（比如向打印头发送点阵图数据）
SPI.transfer(0xAA); 
SPI.transfer(0x55);

// 通信结束，释放总线，让其他 SPI 设备可以使用
SPI.endTransaction(); 
```

SIP配置为：

```c
static SPISettings HEAD_SPI(1000000, MSBFIRST, SPI_MODE0); 
// ESP32 的 VSPI 默认引脚：SCLK=18, MISO=19, MOSI=23, SS=5 
// 这里只用到时钟与 MOSI，所以把 MISO/SS 设成 -1 让库跳过 
SPI.begin(PIN_CLK, -1, PIN_DI, -1);
```

1000000：时钟频率（1MHz）

MSBFIRST：高位先发，如0x8F：1000 1111。发送顺序：1->0->0->0->1...

SPI_MODE0：使用SPI模式0，根据打印头手册决定，CPOL：空闲低电平，CPHA：第一个边沿采样



### SPI给打印头发数据：

上电时先清空移位寄存器数据（刚上电的值时随即的）

每发送完一个数据快速拉低（LAT 低电平至少 0.5µs）再拉高LAT锁存数据，发送数据要先选中再释放

### STB选通信号：

置1指定的STB段加热，置0关闭。

加热后应该迅速关闭（一般为800us ）。
