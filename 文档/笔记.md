**连接流程**：上位机连接到蓝牙设备后，依次发送不同的10个命令码进行握手，打印机每收到一个命令都应答，不回应就一直重发到超时

**通信流程：**                                                                                                     

```
┌──────┬──────┬──────┬───────┬───────┬─────────┬────────────┬──────┐
│ 0x02 │ type │ idx  │ lenL  │ lenH  │ payload │ CRC32 (LE) │ 0x03 │
└──────┴──────┴──────┴───────┴───────┴─────────┴────────────┴──────┘
  1B     1B     1B     1B      1B       len B        4B         1B
固定帧头 命令码  包序号 载荷长度  载荷长度    载荷       CRC32校验   固定帧尾
总长 = len + 10，单包 len ≤ 1920（打印数据 = 40 行）
```

**电机驱动流程：**电机为两相四线双极步进电机，由于芯片3.3v无法直接驱动电机，所以要用电机驱动芯片（**TC1508S**），通过4 个 IO口 驱动四相（A+/A−/B+/B−）。采用八拍（1-2 相交替）半步驱动，相位顺序为 A+ → A+B+ → B+ → A−B+ → A− → A−B− → B− → A+B−，每拍走纸 0.03125mm，即每毫米 32 步、每行（0.125mm）4 步；出纸方向对应相位递减（逆时针）。

**打印下发流程**：上位机分包下发 数据，打印机接收一包数据缓存（最大64K）并回 ACK，发完数据包后再发送打印指令触发打印，打印机收到触发后先回 ACK 再开始打印

**打印流程：**打印过程中，先判断是否有纸以及电池电压（电压阈值3.55），不满足不会打印，
打开VH使能，打印机一行有384个加热点，SPI先发送48字节数据，然后LAT锁存数据，6个STB段再轮流加热，走纸一行再重复
全部打印完成后关闭VH再走纸，

**电量检测流程：**通过分压电路获取电池电压的ADC值，再通过ADC的值与分压电路反推得到当前实际电池电压值，再通过查表法获取对应电压电池的电量。

**缺纸检测：**打印头内置反射光电传感器，有纸时红外线反射无纸不反射，并通过电压比较器输出高低电平来表示是否缺纸

**打印头温度检测：**打印头内置了NTC热敏电阻测温电路，温度越高，NTC 阻值越小，读到对应ADC的值后，根据对应的公式可以得到当前温度

# ESP32：

型号：ESP32-WROOM-32E，该模组为2.4 GHz Wi-Fi + 蓝牙 + 低功耗蓝牙模组，内置ESP32系列芯片，采用Xtensa双核32位LX6处理器，可选4/8/16 MB flash，有26个GPIO，外设丰富，具备板上PCB天线或外部天线连接器。

## SPI配置：

SPI的使用：

```c
SPI.beginTransaction(HEAD_SPI); 
// 发送数据（比如向打印头发送点阵图数据）
SPI.transfer(0xAA); 
SPI.transfer(0x55);
// 通信结束，释放总线，让其他 SPI 设备可以使用
SPI.endTransaction(); 
```

SIP配置为：

```c
static SPISettings HEAD_SPI(1000000, MSBFIRST, SPI_MODE0); 
// ESP32 的 VSPI 默认引脚：SCLK=18, MISO=19, MOSI=23, SS=5 
// 这里只用到时钟与 MOSI，所以把 MISO/SS 设成 -1 让库跳过 
SPI.begin(PIN_CLK, -1, PIN_DI, -1);
```

1000000：时钟频率（1MHz）

MSBFIRST：高位先发，如0x8F：1000 1111。发送顺序：1->0->0->0->1...

SPI_MODE0：使用SPI模式0，根据打印头手册决定，CPOL：空闲低电平，CPHA：第一个边沿采样

# 热敏打印头：

打印头如何驱动

### STB选通信号：

1、一行有384个加热点，共48字节，48x8

2、每发送完一个数据快速拉高（LAT 低电平至少 0.5µs）再拉低LAT锁存数据，发送数据要先选中再释放

3、加热为6段独立控制，6x64=384，分段的目的：降低瞬时电流；6 段同时 加热需要 18A，分段轮流则只要

4、置1指定的STB段加热，置0关闭，上电时先清空移位寄存器数据（刚上电的值为随机，会出现置1的情况导致过热）。

5、加热后应该迅速关闭（加热时间一般为800us ）。

**6、STB冷却时时间不能太短，升压电容来不及回充，导致只能打印前几行。**

# 电池电压检测：

电池型号为：**18650锂电池**，满电电压4.2V，欠电电压3.7V。

**原理：**

通过分压电路获取电池电压的ADC值

分压计算公式（VBAT_OUT*R2/（R1+R2）=VADC）得到ADC的值

再通过ADC的值反推得到当前电压值

反推（VBAT_OUT=VADC*（R1+R2）/R2）得到当前实际电压值

由于电池放电曲线是高度非线性的，所以需要通过查表法获取对应的点亮百分比。


在代码中：使用analogReadMilliVolts(pin)函数可以直接返回对应引脚得到校准后的毫伏值，获取后直接*2（根据分压系数得到）得到当前实际电压值
