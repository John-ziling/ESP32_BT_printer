# ESP32：

## SPI配置：

SPI的使用：

```c
SPI.beginTransaction(HEAD_SPI); 
// 发送数据（比如向打印头发送点阵图数据）
SPI.transfer(0xAA); 
SPI.transfer(0x55);
// 通信结束，释放总线，让其他 SPI 设备可以使用
SPI.endTransaction(); 
```

SIP配置为：

```c
static SPISettings HEAD_SPI(1000000, MSBFIRST, SPI_MODE0); 
// ESP32 的 VSPI 默认引脚：SCLK=18, MISO=19, MOSI=23, SS=5 
// 这里只用到时钟与 MOSI，所以把 MISO/SS 设成 -1 让库跳过 
SPI.begin(PIN_CLK, -1, PIN_DI, -1);
```

1000000：时钟频率（1MHz）

MSBFIRST：高位先发，如0x8F：1000 1111。发送顺序：1->0->0->0->1...

SPI_MODE0：使用SPI模式0，根据打印头手册决定，CPOL：空闲低电平，CPHA：第一个边沿采样

# 热敏打印头：

### STB选通信号：

1、一行有384个加热点，共48字节，48x8

2、每发送完一个数据快速拉低（LAT 低电平至少 0.5µs）再拉高LAT锁存数据，发送数据要先选中再释放

3、加热为6段独立控制，6x64=384，分段的目的：降低瞬时电流；6 段同时 加热需要 18A，分段轮流则只要

4、置1指定的STB段加热，置0关闭，上电时先清空移位寄存器数据（刚上电的值为随机，会出现置1的情况导致过热）。

5、加热后应该迅速关闭（加热时间一般为800us ）。

## 电机：

**电机类型：双极性两相步进电机**

**八拍序列：**

```c

static const uint8_t motor_step_table[8][4] = {
    {1,0,0,0}, // A+
    {1,0,1,0}, // A+ B+
    {0,0,1,0}, // B+
    {0,1,1,0}, // A- B+
    {0,1,0,0}, // A-
    {0,1,0,1}, // A- B-
    {0,0,0,1}, // B-
    {1,0,0,1}  // A+ B-
};
```

**电机出纸使用逆时针旋转**

电机走1mm所需要32步，每步保持时间为500us，太快会导致丢步。

每步走完都将线圈释放，防止一直通电发热。

## 缺纸检测：

LM393ADR：双路电压比较器（只用了一路）

作用：将打印头的光电传感器（PHE）输出的**模拟信号**，转换成单片机（ESP32）能识别的**数字高低电平**。

输出端为开漏输出，所以要在输出端接一个上拉电阻

程序中缺纸时串口打印1，有纸返回0

用非阻塞方式获取上次警报时间并判定，来实现两秒一次警报

# 电池电压检测：

电池型号为：**18650锂电池**，满电电压4.2V，欠电电压3.7V。

**原理：**

通过分压电路获取电池电压的ADC值

分压计算公式（VBAT_OUT*R2/（R1+R2）=VADC）得到ADC的值

再通过ADC的值反推得到当前电压值

反推（VBAT_OUT=VADC*（R1+R2）/R2）得到当前实际电压值

由于电池放电曲线是高度非线性的，所以需要通过查表法获取对应的点亮百分比。


在代码中：使用analogReadMilliVolts(pin)函数可以直接返回对应引脚得到校准后的毫伏值，获取后直接*2（根据分压系数得到）得到当前实际电压值
